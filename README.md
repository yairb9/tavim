# התווים שלי – אפליקציה לטלפון

אפליקציה לניהול תווי ויקטורי (מולטיפס). מתקינים אותה פעם אחת, ואז אפשר לשתף אליה צילום מסך מכל מקום בטלפון.

## העלאה ל-GitHub Pages (פעם אחת, בערך 10 דקות, אפשר מהמחשב)

1. נרשמים בחינם ב-github.com.
2. יוצרים מאגר חדש (New repository) בשם `tavim`, מסמנים Public, ולוחצים Create repository.
3. בעמוד המאגר לוחצים על "uploading an existing file", גוררים את כל הקבצים מהתיקייה (לא את התיקייה עצמה), ולוחצים Commit changes.
4. נכנסים ל-Settings ← Pages. תחת Branch בוחרים `main` ו-`/ (root)`, ולוחצים Save.
5. אחרי דקה או שתיים תופיע כתובת בסגנון `https://השם-שלך.github.io/tavim/`.

## התקנה בטלפון (אנדרואיד)

1. פותחים את הכתובת ב-Chrome.
2. תפריט שלוש הנקודות ← "התקנת אפליקציה" (או "הוספה למסך הבית").
3. מעכשיו, בכל שיתוף של צילום מסך תופיע האפשרות "תווים".

אם "תווים" לא מופיע בתפריט השיתוף מיד, פותחים את האפליקציה פעם אחת מהאייקון ומנסים שוב.

## חשוב לדעת

- קריאת הספרות נעשית בטלפון עצמו. בפעם הראשונה צריך אינטרנט כדי להוריד את רכיב הקריאה (כמה מגה), ואחר כך הוא נשמר.
- תמיד מוצג מסך אישור עם הצילום, כדי להשוות את הספרות לפני ההוספה.
- הרשימה נשמרת רק בטלפון. מומלץ לשמור מדי פעם קובץ גיבוי (בתחתית האפליקציה ← גיבוי).
- המאגר ציבורי, אבל הוא מכיל רק את קוד האפליקציה. התווים שלך לא עולים לשם אף פעם.
