# התווים שלי

אפליקציית ווב לטלפון לניהול תווי קנייה דיגיטליים של ויקטורי (מולטיפס). משתפים אליה צילום מסך של תו, היא קוראת ממנו את מספר התו, היתרה ותאריך ההטענה, ושומרת אותו ברשימה. בקופה מציגים לקופאית את המספר בגדול, כ-QR או כברקוד.

האפליקציה רצה כולה בטלפון. אין שרת, אין חשבון משתמש, והתווים לא נשלחים לשום מקום.

## מה האפליקציה עושה

**הוספת תווים**
- שיתוף צילום מסך ישירות מהגלריה לאפליקציה, דרך תפריט השיתוף של אנדרואיד. אפשר לשתף כמה צילומים יחד.
- בחירת צילומים מתוך האפליקציה, גם הרבה בבת אחת, עם פס התקדמות וכפתור עצירה.
- הקלדה ידנית של מספר התו, היתרה ותאריך ההטענה.
- מסך בדיקה לכל צילום: מוצג הצילום ולידו מה שזוהה, ואפשר לתקן לפני ההוספה.

**מניעת כפילויות**
- צילום שכבר נקרא מזוהה לפי טביעת אצבע דיגיטלית ומדולג עליו.
- תו שכבר ברשימה לא נוסף שוב. אם בצילום החדש יש פרטים שחסרו, או יתרה נמוכה יותר, התו הקיים מתעדכן.
- תו שנמצא בפח חוזר לרשימה אם מעלים שוב את הצילום שלו.

**ניהול**
- יתרה עדכנית לכל תו (הנתון המרכזי), וגם הסכום שהוטען במקור.
- תאריך הטענה, ותוקף שמחושב אוטומטית: 5 שנים מתאריך ההטענה. התראה כשנשאר פחות מחודש.
- מימוש מלא או חלקי. במימוש חלקי היתרה יורדת, ובאפס התו מסומן כמומש.
- תווים שמומשו מוצגים דהויים בתחתית הרשימה.
- מחיקה לפח, עם שחזור או מחיקה לצמיתות.
- חלון אישור לפני כל פעולה, עם הסכום ומספר התו (למשל "למחוק את התו על סך ₪50?"), ואחריה אפשרות ביטול לכמה שניות.
- הודעת הצלחה אחרי הוספה, עם הסכום שנוסף.
- לשוניות נפרדות לתווים פעילים, לתווים שמומשו ולפח.

**בקופה**
- מסך הקראה עם המספר מחולק לקבוצות גדולות של ספרות.
- ברקוד שהקופאית יכולה לסרוק, בשלושה סוגים לבחירה: Code 128 (ברירת המחדל), Code 39, ו-EAN-13 כשהמספר מתאים לו. הבחירה נשמרת.
- המסך נשאר דלוק כל עוד מסך ההקראה פתוח.
- מעבר מהיר לתו הבא.

**ניווט ומראה**
- כפתור "חזרה" של אנדרואיד סוגר את החלון או המסך הפתוח, במקום לצאת מהאפליקציה.
- גרירה של חלון למטה, מהפס העליון או מהכותרת, סוגרת אותו.
- מצב בהיר, כהה, או לפי הגדרת הטלפון, בהגדרות.

**גיבוי ואיפוס**
- שמירה וטעינה של קובץ גיבוי, להעברה לטלפון אחר או לשחזור.
- איפוס זיכרון הצילומים: מאפשר לקרוא שוב צילומים ישנים בלי למחוק את הרשימה.
- איפוס מלא, עם אישור ואפשרות ביטול.

## הטכנולוגיות

### בסיס
- **‏HTML, ‏CSS ו-JavaScript רגיל**, בלי framework ובלי שלב בנייה. כל האפליקציה היא קובץ `index.html` אחד.
- **‏PWA ‏(Progressive Web App):** אתר שמותקן בטלפון ומתנהג כמו אפליקציה רגילה, עם אייקון, מסך מלא ועבודה בלי אינטרנט.
- **‏GitHub Pages** לאירוח, בחינם.

### ממשקי דפדפן (Web APIs)
| ממשק | למה הוא משמש |
|---|---|
| `Web App Manifest` | שם, אייקון וצבע האפליקציה, והרישום שלה בתפריט השיתוף |
| `Web Share Target` | קבלת צילומי מסך מתפריט השיתוף של אנדרואיד |
| `Service Worker` | עבודה בלי אינטרנט, קבלת הקבצים המשותפים, ושמירת הספריות במטמון |
| `Cache API` | "תיבת דואר" שבה ה-Service Worker מחזיק צילום משותף עד שהאפליקציה נפתחת, ושמירת קבצי האפליקציה |
| `localStorage` | שמירת רשימת התווים, זיכרון הצילומים, סוג הברקוד והמראה |
| `History API` | כפתור "חזרה" שסוגר חלונות במקום לצאת מהאפליקציה |
| `Pointer Events` | גרירת חלון למטה כדי לסגור אותו |
| `StorageManager.persist()` | בקשה מהדפדפן לא למחוק את הנתונים כשחסר מקום |
| `Web Crypto (SHA-256)` | טביעת אצבע לכל צילום, לזיהוי צילום שכבר נקרא |
| `Canvas` ו-`createImageBitmap` | הכנת התמונה לקריאה: הגדלה, גווני אפור והגברת ניגודיות |
| `Screen Wake Lock` | השארת המסך דלוק במסך ההקראה |
| `<dialog>` | חלונות האישור, הודעות ההצלחה והחלונות הנפתחים מלמטה |

### ספריות חיצוניות
כל הספריות נטענות מ-CDN בגרסה קבועה, ונשמרות בטלפון אחרי הטעינה הראשונה.

| ספרייה | גרסה | תפקיד |
|---|---|---|
| `Tesseract.js` | 5.1.1 | זיהוי טקסט בתמונה (OCR), ישירות בטלפון |
| `JsBarcode` | 3.11.6 | יצירת ברקוד |
| `Google Fonts – IBM Plex Sans Hebrew` | – | הגופן של האפליקציה |

## איך עובד זיהוי הטקסט

הקריאה נעשית בטלפון עם Tesseract.js, במודל האנגלי ובמצב "טקסט מפוזר" (`PSM 11`), שמתאים לצילומי מסך של אפליקציות.

נבחר דווקא המודל האנגלי, כי הוא קורא ספרות בצורה אמינה. במודל העברי נעלמו ספרות מתוך המספרים. החיסרון הוא שהמילים בעברית יוצאות משובשות, ולכן הזיהוי לא מסתמך על מילים כמו "יתרה" או "תאריך הטענה", אלא על צורה ומיקום:

- **מספר התו:** רצף של בדיוק 13 ספרות. מותר שיהיו בתוכו רווחים או מקפים, כמו ב-‎162076500-8855.
- **תאריכים:** בפורמט שנה-חודש-יום (‎2026-10-25, כמו במולטיפס) או יום/חודש/שנה. תאריך ההטענה הוא התאריך המוקדם ביותר שאינו בעתיד.
- **סכומים:** מספר שליד סימן ₪ או ש״ח, מספר שעומד לבד בשורה (היתרה הגדולה בכרטיס), או מספר שמופיע לפני נקודתיים (״סכום הטענה: ₪50״ נקרא כ-`50 :`). לפעמים ₪ נקרא כספרה 5 בתחילת המספר (550 במקום 50); כשהסכום השני בצילום מאשר את זה, ה-5 מוסר.
- **סימני ₪ משובשים:** ₪ נקרא לפעמים כאותיות `M`, `w` או `RI`, ולכן גם אלה נחשבים, אבל רק כשהם צמודים למספר וכשהסכום הוא לפחות 5 ₪. ככה ג׳יבריש עברי לא מזוהה כסכום.
- **יתרה מול הוטען:** הסכום הקרוב ביותר למספר התו הוא היתרה. הסכום הקרוב ביותר לתאריך ההטענה הוא הסכום שהוטען.
- **כמה תווים בצילום אחד:** כל תו מקבל את הסכום והתאריך הקרובים אליו.

בגלל שהזיהוי מבוסס על ניחוש חכם, כל צילום עובר מסך בדיקה לפני ההוספה.

## איפה הנתונים נשמרים

הכול נשמר ב-`localStorage` של הדפדפן, בטלפון בלבד, תחת המפתחות האלה:

| מפתח | תוכן |
|---|---|
| `victory-vouchers-v1` | רשימת התווים |
| `victory-shots-v1` | טביעות האצבע של צילומים שנקראו |
| `victory-barfmt` | סוג הברקוד שנבחר |
| `victory-theme` | המראה שנבחר (בהיר או כהה; בלי ערך = לפי הטלפון) |

כל תו נשמר כך:

| שדה | משמעות |
|---|---|
| `code` | מספר התו, 13 ספרות |
| `balance` | יתרה עדכנית |
| `loadAmount` | הסכום שהוטען |
| `loaded` | תאריך ההטענה |
| `shot` | טביעת האצבע של הצילום שממנו נקרא |
| `used`, `usedAt` | האם מומש, ומתי |
| `deleted`, `deletedAt` | האם בפח, ומתי |

הנתונים משויכים לכתובת המדויקת של האתר. אם שם המאגר או שם המשתמש ב-GitHub משתנים, הטלפון רואה בזה אפליקציה חדשה והרשימה נראית ריקה. לכן לא משנים אותם, ושומרים קובץ גיבוי מדי פעם.

## התקנה

### העלאה ל-GitHub Pages (פעם אחת)
1. נרשמים ב-github.com.
2. יוצרים מאגר חדש בשם `tavim`, ציבורי.
3. מעלים את כל הקבצים: `Add file` ואז `Upload files`, ובסוף `Commit changes`.
4. נכנסים ל-`Settings` ואז `Pages`. תחת `Branch` בוחרים `main` ו-`/ (root)`, ולוחצים `Save`.
5. אחרי דקה או שתיים האתר זמין בכתובת:
   `https://USERNAME.github.io/tavim/`

### התקנה בטלפון (אנדרואיד)
1. פותחים את הכתובת ב-Chrome.
2. בתפריט שלוש הנקודות בוחרים "התקנת אפליקציה" (או "הוספה למסך הבית").
3. פותחים את האפליקציה פעם אחת מהאייקון.
4. מעכשיו "תווים" מופיע בתפריט השיתוף של צילומי מסך.

## עדכון גרסה
1. מעלים את הקבצים החדשים לאותו מאגר: `Add file`, ואז `Upload files`, ואז `Commit changes`. קבצים עם אותו שם מחליפים את הישנים.
2. בלשונית `Actions` מופיע וי ירוק כשהעדכון באוויר.
3. בטלפון סוגרים את האפליקציה לגמרי ופותחים שוב. ה-Service Worker בודק תמיד מול השרת אם יש גרסה חדשה.

הרשימה בטלפון לא נפגעת מעדכון. לפני שינוי גדול כדאי בכל זאת לשמור קובץ גיבוי.

## מגבלות ידועות
- הזיהוי מותאם לצילומי מסך של מולטיפס. בצילומים במבנה אחר ייתכן שהסכום או התאריך לא יזוהו, ואז ממלאים אותם במסך הבדיקה.
- בקריאה הראשונה צריך אינטרנט, כדי להוריד את רכיב הזיהוי (כמה מגה). אחר כך הוא שמור בטלפון.
- הרשימה שמורה בטלפון אחד בלבד. מעבר לטלפון אחר נעשה עם קובץ גיבוי.
- שיתוף מתפריט השיתוף עובד באנדרואיד עם Chrome. באייפון אפשר להשתמש בכפתור "הוספה מצילום מסך".
- מחיקת נתוני האתר בהגדרות של Chrome מוחקת גם את הרשימה.

## פרטיות
המאגר ב-GitHub ציבורי, אבל הוא מכיל רק את קוד האפליקציה. הצילומים, מספרי התווים והיתרות נשמרים רק בטלפון, וזיהוי הטקסט נעשה בטלפון עצמו.
